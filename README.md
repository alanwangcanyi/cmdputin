# CMDPutin

CMDPutin 是给没有粘贴功能的控制台用的 macOS 小工具。选好目标窗口，输入或粘贴命令，CMDPutin 就会模拟键盘逐字输入。支持单条命令和多行脚本。

## 安装与启动

打开 `dist/CMDPutin-macOS.dmg`，将 CMDPutin 拖入「应用程序」。升级时先保留需要的草稿并退出旧版，再替换应用。该通用安装包包含 Apple 芯片和 Intel 两种原生架构，最低系统版本为 macOS 13。

```sh
open "/Applications/CMDPutin.app"
```

第一次使用，点击「去授权」，在「系统设置 → 隐私与安全性 → 辅助功能」启用 CMDPutin。列表里找不到时点 `+`，按 `⌘⇧G`，输入 `/Applications/CMDPutin.app`。授权后窗口列表会自动刷新。如果替换版本后仍提示未授权，在同一页移除旧条目、重新添加已安装的 CMDPutin 并重开应用。

## 输入一条命令或一段脚本

1. 打开目标控制台，在控制台内点一下要接收输入的位置。目标键盘布局选美式英语（US）。
2. 切回 CMDPutin 或按 `⌃⌘V` 唤起它，「目标窗口」会自动选中刚才操作的窗口。若未识别到，可从下拉列表手动选择。
3. 单条命令模式下，在编辑框按回车或点「输入」。目标收到文字后，可以核对并手动执行。
4. 多行脚本模式下，回车用于编辑。按 `⌘Return` 或点「发送脚本」，核对目标、行数和末尾回车后确认。**原文中的换行可能让 Shell 立即执行上一行。**

菜单栏的 C 图标提供主窗口、设置、历史和关于。设置中可以更换全局组合快捷键、指定启动模式并开启历史。点主窗口左上角的红色 × 后，程序坞图标会收起，菜单栏 C 仍可打开原草稿。点主窗口「收起到侧栏」或菜单栏 C →「收起到侧边」，可收为磨砂玻璃悬浮球。首次出现在屏幕右侧正中，拖动可改变停靠位置，点击可恢复窗口。「设置」中的「侧栏图标置顶」单独控制悬浮球。手动拖到左边或右边收起时，悬停即可展开。「置顶」按钮控制窗口是否浮在其他应用上方。

详细键盘行为、历史和本地配置见[产品说明](PRODUCT.md)。版本需求和验收范围见[需求文档](REQUIREMENTS.md)。

## 本地构建

在项目根目录运行 `bash tools/build_dmg.sh`。脚本使用 macOS 命令行开发工具编译 `macOS/` 下的 Swift AppKit 应用，将 `assets/` 中手绘的黑色 SVG 转为原生图标，并校验包含 arm64 与 x86_64 的通用应用及 DMG。默认采用临时签名，可通过 `CODE_SIGN_IDENTITY` 指定签名身份。

输入规则与存储回归测试可在项目根目录运行：

```sh
bin=$(mktemp -t cmdputin-test) && xcrun swiftc macOS/Model.swift tests/ModelTests.swift -o "$bin" && "$bin" && rm "$bin"
```
